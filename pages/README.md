# 中学2年理科 気象教材アプリ(試作版)

中学2年理科向けに、気温・湿度・露点・雲のでき方を
スライダーとグラフで直感的に理解できるようにしたWebアプリです。
Streamlitのマルチページ機能で、複数の教材を1つのアプリにまとめています。

## ファイル構成

```
humidity_app/
├── app.py                          … ①飽和水蒸気量・湿度・露点(ホーム画面)
├── pages/
│   └── 2_雲のできる高さ.py          … ②雲のできる高さシミュレーター
├── science_utils.py                … 計算ロジック(UIから独立、①②で共通利用)
├── requirements.txt                … 必要なPythonパッケージ
└── data/
    └── saturation_vapor.csv        … 飽和水蒸気量データ(仮データ、差し替え可能)
```

Streamlitのマルチページ機能により、`pages/` フォルダの中にファイルを置くだけで、
アプリ起動時にサイドバーへ自動的にページの一覧(①②)が表示されます。
`app.py` を直接編集する必要はありません。

## Windowsでの起動方法

1. Python(3.9以上を推奨)をインストールしておく
2. コマンドプロンプトまたはPowerShellで、このフォルダ(humidity_app)に移動する

   ```
   cd 保存した場所\humidity_app
   ```

3. 必要なパッケージをインストールする(初回のみ)

   ```
   pip install -r requirements.txt
   ```

4. アプリを起動する(必ず `app.py` を指定してください。個別のページファイルを直接指定しないでください)

   ```
   streamlit run app.py
   ```

5. 自動的にブラウザが開き、`http://localhost:8501` でアプリが表示されます。
   左側のサイドバーから「雲のできる高さ」ページに切り替えられます。
   開かない場合は、表示されたURLを手動でブラウザに入力してください。

6. 終了するときは、コマンドプロンプトの画面で `Ctrl + C` を押します。

## ②雲のできる高さシミュレーターについて(v3で追加)

### 学習目標

- 空気が上昇すると気温が下がること
- 気温が露点に達すると雲ができ始めること
- 地上の気温・湿度によって、雲ができ始める高さが変わること

### 計算上の仮定(簡略モデル)

実際の大気を精密に再現したものではなく、中学校教材用の簡略モデルです。
画面下部にも同じ内容を表示しています。

- 上昇する未飽和の空気の気温:100mにつき **1.0℃** 下がる
- 上昇中の露点:100mにつき **0.2℃** 下がる
- したがって、気温と露点の差は100m上昇するごとに **0.8℃** ずつ縮まる
- 雲底高度 ≈ (地上の気温 − 地上の露点) ÷ 0.8 × 100m

これらの数値は `science_utils.py` の `DRY_LAPSE_RATE_C_PER_100M` /
`DEW_POINT_LAPSE_RATE_C_PER_100M` としてコードの先頭付近にまとめてあり、
値を直接あちこちに埋め込んでいません。教材の設定を変えたい場合は、
この2つの定数を変更するだけで反映されます。

### 山と雲の表示について

- 山の高さは3000mで固定です。
- グラフの縦軸は常に0〜5000mまで表示します。雲底が3000mを超えても、
  「山の上空に雲ができる」ことが分かるように、5000mまでは空に雲を描画します。
- 雲底が5000mも超える場合や、地上の空気が極端に乾燥していて
  この教材の計算モデルの範囲(飽和水蒸気量表:-20〜40℃)を超えてしまう場合は、
  具体的な数値を偽って表示せず、「雲はできない」旨のみを文章で表示します。

### 再利用している既存関数

- `load_saturation_table` / `saturation_at` / `dew_point_from_water_amount`:
  ①のアプリと共通のまま使用しており、飽和水蒸気量や露点の計算を重複実装していません。

### 新規に追加した関数(`science_utils.py`)

- `water_amount_from_relative_humidity(temperature_c, relative_humidity_percent, df)`
- `temperature_at_altitude(ground_temperature_c, altitude_m, ...)`
- `dew_point_at_altitude(ground_dew_point_c, altitude_m, ...)`
- `cloud_base_height(ground_temperature_c, ground_dew_point_c, ...)`
- `compute_cloud_state(ground_temperature_c, ground_relative_humidity_percent, df)`:
  上記をまとめて呼び出す関数。UI側はこれを呼ぶだけでよい設計です。

いずれもStreamlit(UI)に依存しないため、将来のフェーン現象シミュレーターでも
そのまま再利用できます。

## CSVデータの差し替えについて

`data/saturation_vapor.csv` は、現時点では計算式から作った仮の値です。
教科書に準拠した値に差し替える場合は、同じ列名
(`temperature_c`, `saturation_g_m3`)のまま、値だけを書き換えてください。
コード側の修正は不要です(①②どちらのページにも自動的に反映されます)。

## 今後の拡張について

`science_utils.py` は画面(Streamlit)から独立しているため、
フェーン現象や放射冷却など、他の教材でも今回追加した関数
(`temperature_at_altitude` など)をそのまま再利用できます。
新しい教材を追加する場合も、`pages/` フォルダに
ファイルを1つ追加するだけで、既存のページに影響を与えずに拡張できます。
